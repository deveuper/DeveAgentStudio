Runs a command inside a real pseudo-terminal (PTY), returning its output or a session id for ongoing interaction. Unlike the bash tool, this can drive interactive programs (REPLs, watchers, TUI apps) that need a terminal. The command is executed through the platform shell. If the process is still running after the yield window, the output so far is returned together with a session id: feed input to it and poll with the pty_write tool. Output is kept as head+tail; when a program produces enormous output, the middle is replaced by an omission marker.
