Writes input to a running pty session and polls for new output. Non-empty input is permission-gated (reviewable like a command). Pass chars to send text (a newline is NOT appended automatically - include \n when the program should receive Enter). Use "\u0003" for Ctrl+C. Omit chars to only poll. When the process has exited, the response carries the exit code and the session is closed; otherwise the response echoes the session id for further pty_write calls.
